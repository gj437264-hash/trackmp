Your site's real strength isn't a fixed list of 200 keywords—it's the combinations you can generate automatically.

What I would build for TrackMP
  • 100+ reusable SEO page templates (politician, constituency, party, state, election, comparison, rankings, etc.)
  • Automatic title & meta description generation
  • Dynamic JSON-LD (Person, Organization, Election, Breadcrumb, WebPage, FAQ)
  • Internal linking graph connecting politicians, constituencies, parties, elections & rankings
  • Programmatically generated XML sitemaps split by content type
  • Topical hubs (state pages, party pages, election pages) that strengthen authority
With this approach, the site can realistically target well over one million unique search queries while remaining maintainable — everything generated from your MongoDB data. FastAPI + React + MongoDB

2. Automatic Title & Meta Description

rules · not manual
Title pattern
{Name} ({Party}) – MP from {Constituency} | Biography, Performance & Promises | TrackMP
Example: Narendra Modi (BJP) – MP from Varanasi | Biography, Performance & Promises | TrackMP
Meta description
View {Name}'s political profile including biography, education, assets, criminal cases, parliamentary attendance, election history, promises, and performance.
Every politician gets a unique description automatically.
Party page Constituency Election — all have distinct title/meta rules.
